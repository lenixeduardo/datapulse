# Changelog

Todas as mudanças relevantes deste projeto serão documentadas aqui.

O projeto segue versionamento semântico (Semantic Versioning).

## [1.1.0] - 2026-08-26

### Alterado
- Rebrand do projeto para **DataPulse**.
- Dashboard reconstruído conforme a referência branca/azul fornecida.
- KPIs operacionais com ícones vivos e coloridos.
- Gráfico principal de volume de processamento.
- Card dedicado à validação de contratos com simulação interativa da quebra de schema.
- Fila de jobs redesenhada para expor status e progresso do Worker Thread.
- Painel Deploy & Infraestrutura para destacar Docker multi-stage.
- Layout mobile com bottom navigation.

## [1.0.0] - 2026-08-25

### Adicionado
- Primeira versão funcional do SaaS.
- Worker Threads, Zod, API Express, testes e Docker multi-stage.
